Ollama CLI

A simple Python CLI app that sends prompts to a local LLM using Ollama.

Features
Send prompts from the terminal
Uses Llama 3 locally
Built with Python and requests
Simple command-line interface
Installation
1. Install Ollama

Download Ollama:

https://ollama.com/download

2. Pull the model
ollama run llama3
3. Install Python dependencies
pip install requests
Usage

Run the CLI:

py cli.py "What is Python?"
Example
py cli.py "Explain async and await"
